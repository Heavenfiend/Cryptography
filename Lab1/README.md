## Демонстрация DES

Запускай `Main.kt` с рабочей папкой `C:\CryptoLabs\Lab1`.
После примеров 1–3 проверяется известный пример DES, затем запускается пункт 5.
В `demo-input` находятся только `message.txt`, `melody.wav` и `picture.png`.
Программа проверяет также семь длин псевдослучайных массивов байтов.
Всего: 7 режимов × (7 массивов + 3 файла) = 70 проверок восстановления.
Каждый запуск создаёт новую папку `demo-results/run-…` с шифротекстами,
восстановленными файлами и отчётом `report.csv`. Набивка — PKCS7.
Результат проверяется побайтно, а не только по совпадению длины.
Лабораторная работа завершена и сдана.

## Демонстрация DEAL

После пункта 5 `Main.kt` проверяет восстановление одного блока DEAL с ключами
16, 24 и 32 байта, затем запускает пункт 7 через `DealDemo.run()`.
Демонстрация пункта 7 использует ключ 16 байт, блок 16 байт, набивку PKCS7,
семь режимов и те же три файла из `demo-input`.
Проверяются массивы длиной 0, 1, 15, 16, 17, 31 и 1024 байта.
Это ещё 70 проверок, всего для демонстраций DES и DEAL — 140.
Результаты DEAL сохраняются отдельно: `deal-demo-results/run-…`.

В DEAL функция F — полное шифрование DES с раундовым ключом DEAL.
`DesRoundAdapter` настраивает этот ключ и вызывает `DesCipher.encrypt`,
в том числе при расшифровании внешней сети DEAL.
`DealCipher` согласует запись раундов DEAL с нашей общей сетью:
при шифровании меняет половины входа, при расшифровании — половины выхода.

## Учебный пример сети Фейстеля

В `Main.kt` находятся две маленькие реализации интерфейсов:

- `DemoKeyExpansion`: делит двухбайтовый ключ на два однобайтовых раундовых ключа.
- `DemoRoundTransformation`: вычисляет `F(R, K) = R XOR K`.

Размер блока — 2 байта, каждая половина — 1 байт, раундов — 2.
Пример нужен для понимания сети Фейстеля; его функция не обеспечивает стойкость.

Для ключей `06` и `03` и блока `0A 0C`:

```text
Начало:  L = 0A, R = 0C
Раунд 1: T = 0C XOR 06 = 0A; L = 0C, R = 0A XOR 0A = 00
Раунд 2: T = 00 XOR 03 = 03; L = 00, R = 0C XOR 03 = 0F
Выход:   R || L = 0F 00 (обмен половин после всех раундов)
```

При дешифровании используются ключи `03`, затем `06`; восстанавливается `0A 0C`.
Контекст показан на пяти байтах: набивка PKCS7 дополняет их до шести байтов.
В реализации контекста также доступны остальные режимы, виды набивки и методы для файлов.

## Принятые соглашения

- Random Delta реализован как учебный вариант, описанный в `RandomDeltaMode.kt`;
  в условии задания формула режима отсутствует.
- Набивка Zeros не хранит исходную длину и при удалении убирает все конечные нули.
- Файловые операции выполняются асинхронно, но файл загружается в память целиком.
