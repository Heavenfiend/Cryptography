# лаба 2

арифметика, тесты простоты, rsa и атака винера. всё на kotlin.

запуск: открыть Lab2 в IntelliJ и запустить Main.kt, нужен jdk 17+.
из PowerShell: `./run.ps1`, проверки — `./run.ps1 -Test`.

ферма — чистый, без подтверждения другими тестами. для чисел кармайкла
заданная вероятность не гарантируется, параметр задаёт число итераций.
фурье через Double, n до миллиона — преподаватель разрешил.
